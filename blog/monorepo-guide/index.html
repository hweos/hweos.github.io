Monorepo 实践指南

September 1, 2024 · 4 min read
Mason
Full Stack Developer

Monorepo 将多个项目放在一个仓库管理，便于代码共享和统一工具链。本文介绍 Monorepo 的搭建和最佳实践。

🎯 什么是 Monorepo​

Monorepo：多个项目在一个 Git 仓库中
Polyrepo：每个项目一个独立仓库

Monorepo 不等于 Monolith（单体应用）

优缺点​

优点缺点
代码复用简单仓库体积大
统一工具链权限管理复杂
原子化提交CI/CD 需要优化
依赖管理统一学习成本
重构更方便

🛠️ 工具选择​

工具包管理构建缓存任务编排
pnpm workspace✅❌❌
Turborepo❌✅✅
Nx❌✅✅
Lerna✅❌✅

推荐组合：pnpm + Turborepo

🚀 搭建步骤​

1. 初始化项目​

mkdir my-monorepo && cd my-monorepo
pnpm init

2. 配置 pnpm workspace​

# pnpm-workspace.yaml
packages:
  - 'apps/*'
  - 'packages/*'

3. 根目录 package.json​

{
  "name": "my-monorepo",
  "private": true,
  "scripts": {
    "dev": "turbo dev",
    "build": "turbo build",
    "lint": "turbo lint",
    "test": "turbo test",
    "clean": "turbo clean"
  },
  "devDependencies": {
    "turbo": "^1.10.0"
  },
  "packageManager": "pnpm@8.10.0"
}

4. 配置 Turborepo​

// turbo.json
{
  "$schema": "https://turbo.build/schema.json",
  "pipeline": {
    "build": {
      "dependsOn": ["^build"],
      "outputs": ["dist/**", ".next/**"]
    },
    "dev": {
      "cache": false,
      "persistent": true
    },
    "lint": {},
    "test": {
      "dependsOn": ["build"]
    },
    "clean": {
      "cache": false
    }
  }
}

📦 创建共享包​

packages/ui/package.json​

{
  "name": "@repo/ui",
  "version": "0.0.0",
  "private": true,
  "main": "./src/index.ts",
  "types": "./src/index.ts",
  "exports": {
    ".": "./src/index.ts",
    "./button": "./src/button.tsx"
  },
  "scripts": {
    "lint": "eslint src/",
    "build": "tsup src/index.ts --format esm,cjs --dts"
  },
  "peerDependencies": {
    "react": "^18.0.0"
  },
  "devDependencies": {
    "@repo/config": "workspace:*",
    "tsup": "^7.0.0",
    "typescript": "^5.0.0"
  }
}

packages/ui/src/button.tsx​

import { ButtonHTMLAttributes } from 'react';

interface ButtonProps extends ButtonHTMLAttributes<HTMLButtonElement> {
  variant?: 'primary' | 'secondary';
}

export function Button({ variant = 'primary', children, ...props }: ButtonProps) {
  return (
    <button className={`btn btn-${variant}`} {...props}>
      {children}
    </button>
  );
}

packages/ui/src/index.ts​

export { Button } from './button';

🔗 包之间的依赖​

在应用中使用共享包​

// apps/web/package.json
{
  "name": "@repo/web",
  "dependencies": {
    "@repo/ui": "workspace:*",
    "@repo/utils": "workspace:*"
  }
}
// apps/web/src/app/page.tsx
import { Button } from '@repo/ui';
import { formatDate } from '@repo/utils';

export default function Page() {
  return (
    <div>
      <Button onClick={() => console.log('clicked')}>
        Click me
      </Button>
      <p>{formatDate(new Date())}</p>
    </div>
  );
}

安装依赖​

# 安装到特定包
pnpm add lodash --filter @repo/web

# 安装到根目录
pnpm add -D typescript -w

# 安装到所有包
pnpm add -r react

⚙️ 共享配置​

packages/config/tsconfig/base.json​

{
  "compilerOptions": {
    "target": "ES2020",
    "lib": ["ES2020", "DOM", "DOM.Iterable"],
    "module": "ESNext",
    "moduleResolution": "bundler",
    "strict": true,
    "skipLibCheck": true,
    "declaration": true,
    "declarationMap": true,
    "esModuleInterop": true,
    "forceConsistentCasingInFileNames": true,
    "isolatedModules": true,
    "jsx": "react-jsx"
  }
}

在包中使用​

// packages/ui/tsconfig.json
{
  "extends": "@repo/config/tsconfig/base.json",
  "compilerOptions": {
    "outDir": "./dist"
  },
  "include": ["src"],
  "exclude": ["node_modules", "dist"]
}

🏃 运行命令​

开发​

# 运行所有应用
pnpm dev

# 只运行特定应用
pnpm dev --filter @repo/web

# 运行应用及其依赖
pnpm dev --filter @repo/web...

构建​

# 构建所有
pnpm build

# 只构建变更的包
turbo build --filter=[HEAD^1]

# 并行构建
turbo build --concurrency=10

缓存​

# 查看缓存状态
turbo build --dry-run

# 强制忽略缓存
turbo build --force

# 远程缓存（团队共享）
turbo login
turbo link

📋 版本管理​

使用 Changesets​

pnpm add -Dw @changesets/cli
pnpm changeset init

添加变更​

pnpm changeset
# 选择变更的包
# 选择版本类型（patch/minor/major）
# 添加变更描述

发布​

pnpm changeset version  # 更新版本号
pnpm changeset publish  # 发布到 npm

🔧 常见问题​

1. 依赖提升​

# .npmrc
shamefully-hoist=true  # 必要时启用

2. 类型引用​

// tsconfig.json
{
  "compilerOptions": {
    "paths": {
      "@repo/ui": ["../../packages/ui/src"],
      "@repo/utils": ["../../packages/utils/src"]
    }
  }
}

3. 构建顺序​

// turbo.json
{
  "pipeline": {
    "build": {
      "dependsOn": ["^build"]  // 先构建依赖
    }
  }
}

✅ 最佳实践​

1. 包命名统一 scope
   - @repo/ui, @repo/utils, @repo/config

2. 明确包的边界
   - 每个包职责单一
   - 避免循环依赖

3. 统一工具链
   - 共享 ESLint、Prettier、TypeScript 配置
   - 统一脚本命名（dev, build, lint, test）

4. 优化 CI/CD
   - 利用缓存减少构建时间
   - 只构建受影响的包

5. 文档完善
   - 每个包有 README
   - 贡献指南
