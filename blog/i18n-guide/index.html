国际化 (i18n) 最佳实践

February 20, 2025 · 4 min read
Mason
Full Stack Developer

国际化让应用触达全球用户。本文介绍 React 应用的国际化实现方案和最佳实践。

🎯 国际化基础​

相关术语​

术语全称含义
i18nInternationalization国际化（使应用支持多语言）
l10nLocalization本地化（翻译和适配）
locale-区域设置（zh-CN, en-US）

需要国际化的内容​

- 文本内容
- 日期时间格式
- 数字和货币格式
- 排序规则
- 文本方向 (LTR/RTL)
- 图片和图标

📦 react-i18next​

安装​

npm install react-i18next i18next i18next-browser-languagedetector

配置​

// src/i18n/index.ts
import i18n from 'i18next';
import { initReactI18next } from 'react-i18next';
import LanguageDetector from 'i18next-browser-languagedetector';

import en from './locales/en.json';
import zh from './locales/zh.json';

i18n
  .use(LanguageDetector)
  .use(initReactI18next)
  .init({
    resources: {
      en: { translation: en },
      zh: { translation: zh },
    },
    fallbackLng: 'en',
    interpolation: {
      escapeValue: false,
    },
    detection: {
      order: ['localStorage', 'navigator'],
      caches: ['localStorage'],
    },
  });

export default i18n;

翻译文件​

// src/i18n/locales/en.json
{
  "common": {
    "welcome": "Welcome",
    "login": "Login",
    "logout": "Logout"
  },
  "home": {
    "title": "Home Page",
    "greeting": "Hello, {{name}}!"
  },
  "errors": {
    "required": "This field is required",
    "email": "Invalid email address"
  }
}
// src/i18n/locales/zh.json
{
  "common": {
    "welcome": "欢迎",
    "login": "登录",
    "logout": "退出"
  },
  "home": {
    "title": "首页",
    "greeting": "你好，{{name}}！"
  },
  "errors": {
    "required": "此字段必填",
    "email": "邮箱格式不正确"
  }
}

使用​

// 引入 i18n 配置
import './i18n';

// 使用 Hook
import { useTranslation } from 'react-i18next';

function HomePage() {
  const { t, i18n } = useTranslation();

  return (
    <div>
      <h1>{t('home.title')}</h1>
      <p>{t('home.greeting', { name: 'John' })}</p>
      
      <button onClick={() => i18n.changeLanguage('en')}>
        English
      </button>
      <button onClick={() => i18n.changeLanguage('zh')}>
        中文
      </button>
    </div>
  );
}

🔢 复数和插值​

复数​

// en.json
{
  "items": {
    "count_one": "{{count}} item",
    "count_other": "{{count}} items"
  },
  "messages": {
    "count_zero": "No messages",
    "count_one": "1 message",
    "count_other": "{{count}} messages"
  }
}
t('items.count', { count: 1 });  // "1 item"
t('items.count', { count: 5 });  // "5 items"

嵌套插值​

{
  "user": {
    "info": "{{name}} has {{count}} posts"
  }
}
t('user.info', { name: 'John', count: 10 });
// "John has 10 posts"

富文本​

{
  "terms": "Please read our <link>terms of service</link>"
}
import { Trans } from 'react-i18next';

<Trans i18nKey="terms">
  Please read our <a href="/terms">terms of service</a>
</Trans>

📅 日期和数字格式化​

Intl API​

// 日期格式化
const date = new Date();

new Intl.DateTimeFormat('zh-CN').format(date);
// "2025/2/20"

new Intl.DateTimeFormat('en-US', {
  year: 'numeric',
  month: 'long',
  day: 'numeric',
}).format(date);
// "February 20, 2025"

// 数字格式化
new Intl.NumberFormat('zh-CN').format(1234567.89);
// "1,234,567.89"

new Intl.NumberFormat('de-DE').format(1234567.89);
// "1.234.567,89"

// 货币格式化
new Intl.NumberFormat('zh-CN', {
  style: 'currency',
  currency: 'CNY',
}).format(99.99);
// "¥99.99"

new Intl.NumberFormat('en-US', {
  style: 'currency',
  currency: 'USD',
}).format(99.99);
// "$99.99"

封装 Hook​

import { useTranslation } from 'react-i18next';

function useFormatter() {
  const { i18n } = useTranslation();
  const locale = i18n.language;

  return {
    formatDate: (date: Date, options?: Intl.DateTimeFormatOptions) => {
      return new Intl.DateTimeFormat(locale, options).format(date);
    },
    formatNumber: (num: number, options?: Intl.NumberFormatOptions) => {
      return new Intl.NumberFormat(locale, options).format(num);
    },
    formatCurrency: (amount: number, currency = 'USD') => {
      return new Intl.NumberFormat(locale, {
        style: 'currency',
        currency,
      }).format(amount);
    },
  };
}

// 使用
function Price({ amount }: { amount: number }) {
  const { formatCurrency } = useFormatter();
  return <span>{formatCurrency(amount, 'CNY')}</span>;
}

🔄 语言切换​

语言选择器​

function LanguageSelector() {
  const { i18n } = useTranslation();

  const languages = [
    { code: 'en', name: 'English', flag: '🇺🇸' },
    { code: 'zh', name: '中文', flag: '🇨🇳' },
    { code: 'ja', name: '日本語', flag: '🇯🇵' },
  ];

  return (
    <select
      value={i18n.language}
      onChange={(e) => i18n.changeLanguage(e.target.value)}
    >
      {languages.map((lang) => (
        <option key={lang.code} value={lang.code}>
          {lang.flag} {lang.name}
        </option>
      ))}
    </select>
  );
}

持久化​

// 自动保存到 localStorage
i18n.on('languageChanged', (lng) => {
  localStorage.setItem('language', lng);
  document.documentElement.lang = lng;
});

🌐 Next.js 国际化​

配置​

// next.config.js
module.exports = {
  i18n: {
    locales: ['en', 'zh', 'ja'],
    defaultLocale: 'en',
  },
};

路由​

/           → 英文（默认）
/zh         → 中文
/ja         → 日语
/zh/about   → 中文关于页

使用​

import { useRouter } from 'next/router';

function Page() {
  const { locale, locales, push, asPath } = useRouter();

  const changeLocale = (newLocale: string) => {
    push(asPath, asPath, { locale: newLocale });
  };

  return (
    <div>
      <p>Current: {locale}</p>
      {locales?.map((l) => (
        <button key={l} onClick={() => changeLocale(l)}>
          {l}
        </button>
      ))}
    </div>
  );
}

📂 翻译管理​

目录结构​

src/i18n/
├── index.ts
└── locales/
    ├── en/
    │   ├── common.json
    │   ├── home.json
    │   └── errors.json
    └── zh/
        ├── common.json
        ├── home.json
        └── errors.json

命名空间​

i18n.init({
  ns: ['common', 'home', 'errors'],
  defaultNS: 'common',
});
// 使用命名空间
const { t } = useTranslation('home');
t('title');  // 从 home.json

// 跨命名空间
t('common:login');  // 从 common.json

✅ 最佳实践​

翻译键命名​

// ✅ 好的命名
{
  "user.profile.title": "Profile",
  "user.profile.edit": "Edit Profile",
  "error.network": "Network error"
}

// ❌ 不好的命名
{
  "text1": "Profile",
  "btn1": "Edit Profile"
}

避免拼接​

// ❌ 不好
t('hello') + ' ' + name + '!'

// ✅ 好
t('greeting', { name })

提取常量​

// 翻译键常量
export const I18N_KEYS = {
  COMMON: {
    SUBMIT: 'common.submit',
    CANCEL: 'common.cancel',
  },
} as const;

// 使用
t(I18N_KEYS.COMMON.SUBMIT);
