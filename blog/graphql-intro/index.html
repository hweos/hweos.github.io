GraphQL 入门指南

November 1, 2024 · 4 min read
Mason
Full Stack Developer

GraphQL 是一种 API 查询语言，让客户端精确获取所需数据。本文介绍 GraphQL 的核心概念和使用方法。

🎯 GraphQL vs REST​

特性RESTGraphQL
端点多个 /users, /posts单个 /graphql
数据获取固定结构按需查询
过度获取常见避免
多次请求需要多个请求一次请求
版本控制/v1, /v2无需版本
类型系统无强类型

📝 基础语法​

查询 (Query)​

# 基础查询
query {
  user(id: "1") {
    id
    name
    email
  }
}

# 响应
{
  "data": {
    "user": {
      "id": "1",
      "name": "John",
      "email": "john@example.com"
    }
  }
}

嵌套查询​

query {
  user(id: "1") {
    name
    posts {
      title
      comments {
        content
        author {
          name
        }
      }
    }
  }
}

变量​

query GetUser($id: ID!) {
  user(id: $id) {
    name
    email
  }
}

# 变量
{
  "id": "1"
}

别名​

query {
  admin: user(id: "1") {
    name
  }
  guest: user(id: "2") {
    name
  }
}

片段 (Fragment)​

fragment UserFields on User {
  id
  name
  email
  avatar
}

query {
  user(id: "1") {
    ...UserFields
    posts {
      title
    }
  }
  
  users {
    ...UserFields
  }
}

✏️ 变更 (Mutation)​

mutation CreateUser($input: CreateUserInput!) {
  createUser(input: $input) {
    id
    name
    email
  }
}

# 变量
{
  "input": {
    "name": "John",
    "email": "john@example.com"
  }
}
mutation UpdateUser($id: ID!, $input: UpdateUserInput!) {
  updateUser(id: $id, input: $input) {
    id
    name
  }
}

mutation DeleteUser($id: ID!) {
  deleteUser(id: $id) {
    success
    message
  }
}

📡 订阅 (Subscription)​

subscription OnMessageCreated($channelId: ID!) {
  messageCreated(channelId: $channelId) {
    id
    content
    author {
      name
    }
    createdAt
  }
}

🏗️ Schema 定义​

类型定义​

# 对象类型
type User {
  id: ID!
  name: String!
  email: String!
  age: Int
  isActive: Boolean!
  posts: [Post!]!
  createdAt: DateTime!
}

type Post {
  id: ID!
  title: String!
  content: String!
  author: User!
  tags: [String!]
  published: Boolean!
}

# 输入类型
input CreateUserInput {
  name: String!
  email: String!
  age: Int
}

input UpdateUserInput {
  name: String
  email: String
  age: Int
}

# 枚举
enum Role {
  ADMIN
  USER
  GUEST
}

# 接口
interface Node {
  id: ID!
}

type User implements Node {
  id: ID!
  name: String!
}

根类型​

type Query {
  user(id: ID!): User
  users(limit: Int, offset: Int): [User!]!
  post(id: ID!): Post
  posts(authorId: ID): [Post!]!
}

type Mutation {
  createUser(input: CreateUserInput!): User!
  updateUser(id: ID!, input: UpdateUserInput!): User
  deleteUser(id: ID!): Boolean!
  createPost(input: CreatePostInput!): Post!
}

type Subscription {
  userCreated: User!
  postPublished: Post!
}

🖥️ 服务端实现 (Node.js)​

Apollo Server​

import { ApolloServer } from '@apollo/server';
import { startStandaloneServer } from '@apollo/server/standalone';

// 类型定义
const typeDefs = `
  type User {
    id: ID!
    name: String!
    email: String!
  }

  type Query {
    users: [User!]!
    user(id: ID!): User
  }

  type Mutation {
    createUser(name: String!, email: String!): User!
  }
`;

// 解析器
const resolvers = {
  Query: {
    users: () => db.users.findMany(),
    user: (_, { id }) => db.users.findById(id),
  },
  Mutation: {
    createUser: (_, { name, email }) => {
      return db.users.create({ name, email });
    },
  },
};

// 创建服务器
const server = new ApolloServer({
  typeDefs,
  resolvers,
});

const { url } = await startStandaloneServer(server, {
  listen: { port: 4000 },
});

console.log(`Server ready at ${url}`);

解析器上下文​

const resolvers = {
  Query: {
    me: (parent, args, context) => {
      // context 包含请求信息、认证等
      if (!context.user) {
        throw new Error('Not authenticated');
      }
      return context.user;
    },
  },
  User: {
    // 字段解析器
    posts: (parent, args, context) => {
      return db.posts.findByAuthorId(parent.id);
    },
  },
};

// 设置 context
const { url } = await startStandaloneServer(server, {
  context: async ({ req }) => ({
    user: await getUserFromToken(req.headers.authorization),
  }),
});

📱 客户端使用​

Apollo Client (React)​

import { ApolloClient, InMemoryCache, ApolloProvider, gql, useQuery, useMutation } from '@apollo/client';

// 创建客户端
const client = new ApolloClient({
  uri: 'http://localhost:4000/graphql',
  cache: new InMemoryCache(),
});

// Provider
function App() {
  return (
    <ApolloProvider client={client}>
      <UserList />
    </ApolloProvider>
  );
}

useQuery​

const GET_USERS = gql`
  query GetUsers {
    users {
      id
      name
      email
    }
  }
`;

function UserList() {
  const { loading, error, data, refetch } = useQuery(GET_USERS);

  if (loading) return <p>Loading...</p>;
  if (error) return <p>Error: {error.message}</p>;

  return (
    <ul>
      {data.users.map(user => (
        <li key={user.id}>{user.name}</li>
      ))}
    </ul>
  );
}

useMutation​

const CREATE_USER = gql`
  mutation CreateUser($name: String!, $email: String!) {
    createUser(name: $name, email: $email) {
      id
      name
      email
    }
  }
`;

function CreateUserForm() {
  const [createUser, { loading, error }] = useMutation(CREATE_USER, {
    refetchQueries: ['GetUsers'], // 刷新列表
  });

  const handleSubmit = async (e) => {
    e.preventDefault();
    const formData = new FormData(e.target);
    
    await createUser({
      variables: {
        name: formData.get('name'),
        email: formData.get('email'),
      },
    });
  };

  return (
    <form onSubmit={handleSubmit}>
      <input name="name" placeholder="Name" />
      <input name="email" placeholder="Email" />
      <button type="submit" disabled={loading}>
        {loading ? 'Creating...' : 'Create'}
      </button>
      {error && <p>Error: {error.message}</p>}
    </form>
  );
}

🔧 最佳实践​

分页​

type Query {
  posts(first: Int, after: String): PostConnection!
}

type PostConnection {
  edges: [PostEdge!]!
  pageInfo: PageInfo!
}

type PostEdge {
  node: Post!
  cursor: String!
}

type PageInfo {
  hasNextPage: Boolean!
  endCursor: String
}

错误处理​

type MutationResult {
  success: Boolean!
  message: String
  errors: [Error!]
}

type Error {
  field: String
  message: String!
}

N+1 问题​

// 使用 DataLoader 解决
import DataLoader from 'dataloader';

const userLoader = new DataLoader(async (ids) => {
  const users = await db.users.findMany({
    where: { id: { in: ids } },
  });
  return ids.map(id => users.find(u => u.id === id));
});

const resolvers = {
  Post: {
    author: (post) => userLoader.load(post.authorId),
  },
};

📋 对比总结​

场景推荐
简单 CRUDREST
复杂数据关系GraphQL
移动端/带宽敏感GraphQL
公开 APIREST
内部 APIGraphQL
微服务聚合GraphQL

GraphQL 不是 REST 的替代品，而是另一种选择。根据项目需求选择合适的方案。
